# Đề bài 01 (md02_ss04) - [ Khá ] Sắp xếp mảng giảm dần

## Mô tả

Viết chương trình Java để sắp xếp một mảng số nguyên theo thứ tự giảm dần bằng thuật toán sắp xếp nổi bọt.

### Yêu Cầu:

**Khởi Tạo Mảng:**
- Người dùng nhập kích thước của mảng
- Người dùng nhập từng giá trị cho mảng số nguyên

**Sắp Xếp:**
- Sử dụng thuật toán sắp xếp nổi bọt để sắp xếp mảng theo thứ tự giảm dần

**Đầu Ra:**
- Hiển thị mảng đã sắp xếp
