# Đề bài 05 - [ Xuất sắc ] Tính toán chỉ số BMI

## Mô tả

Viết chương trình Java thực hiện cho người dùng nhập vào chỉ số cơ thể và tính được chỉ số BMI của cơ thể mình với công thức như sau:

BMI = Cân nặng (kg) / (Chiều cao (m))²

### Yêu cầu:

- Nhập cân nặng (kg)
- Nhập chiều cao (m)
- Tính và in ra chỉ số BMI
